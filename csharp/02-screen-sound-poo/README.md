# Projeto-Screen-Sound-POO-Csharp
Orientação a Objetos, falando sobre herança, interface e polimorfismo. Linguagem C#
## Destaques do Projeto :pushpin:
- Programação Orientada a Objeto em C#
-  conhecimentos de Orientação a Objetos, aprendendo sobre métodos estáticos, herança e interface. Além disso, organizei o código através de namespaces e pastas de projeto.
- Incorporação de classes Banda e Album no arquivo `Program.cs`, criei uma classe Avaliacao para representar avaliações, reorganizou os menus em uma hierarquia de classes aplicar notas a bandas, álbuns e músicas através da interface IAvaliavel.
